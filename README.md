# Smart Study Scheduler - 3D 📅

> My 3D Study Scheduler with calendar - Plan your studies smartly, visually, and efficiently.

A modern, 3D-enabled study scheduler with calendar integration to help students organize subjects, set deadlines, and track progress.

### 🚀 Live Demo
👉 [smart-study-scheduler-rho.vercel.app](https://smart-study-scheduler-rho.vercel.app)

### ✨ Features
- 📅 **Calendar Integration** - Visual calendar view for all study tasks
- 🎨 **3D Interactive UI** - Modern 3D design for better user experience
- ✅ **Task Management** - Add, edit, delete, and complete study tasks
- ⏰ **Smart Scheduling** - Set dates and priorities for each subject
- 📊 **Progress Tracking** - Track your daily/weekly study progress
- 📱 **Responsive Design** - Works on mobile and desktop

### 🛠️ Tech Stack
- **Frontend:** TypeScript (88.9%), JavaScript, CSS
- **Backend:** Python (7%) - API & date handling
- **Deployment:** Vercel
- **Structure:** `frontend/` + `backend/` (Monorepo)
